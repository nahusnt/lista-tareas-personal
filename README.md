# Lista de Tareas Personal

Proyecto Final Integrador de Programacion II + Bases de Datos II.

## Descripcion

Aplicacion web para administrar tareas personales.

El usuario podrap:

- Agregar tareas.
- Marcar tareas como completadas.
- Eliminar tareas.
- Mantener las tareas guardadas.

## Tecnologias

- Python
- Flask
- MongoDB
- HTML
- CSS
- JavaScript
